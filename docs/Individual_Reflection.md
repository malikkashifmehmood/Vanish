# Individual Project Reflection — Vanish

Working on Vanish has been a valuable learning experience because it allowed me to apply Android development concepts to a practical real-time messaging application. During this project, I worked on developing and improving the Android application using Kotlin and Jetpack Compose.

My work involved improving the user interface, including the chat and join screens, and working with the application's messaging functionality. I also worked on message handling, connection states, message expiration, and the interaction between the Android application and the WebSocket relay. One important part of the project was understanding how messages can be delivered, displayed, and automatically removed after their 30-second lifetime.

I also participated in testing and debugging the application. I ran Gradle tests, built the debug APK, performed Android lint checks, and tested the application on a physical Android device. These activities helped me identify problems, improve the interface, and verify that important application features were working correctly.

Another important responsibility was improving the project documentation. I updated the README, documented the official class protocol, and revised the Design Note to explain the architecture, implementation, message lifecycle, testing, and security limitations.

One of the biggest lessons I learned was that developing a real-time application involves more than designing screens. It also requires careful handling of network connections, synchronization, local storage, message expiration, and error conditions. I also learned the importance of testing and documenting security limitations honestly.

Overall, this project improved my understanding of Android development, Kotlin, Jetpack Compose, WebSocket communication, debugging, and teamwork. It also gave me practical experience in developing and testing an application from implementation through documentation.
